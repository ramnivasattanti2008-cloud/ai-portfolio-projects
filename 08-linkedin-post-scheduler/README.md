# 📅 AI LinkedIn Post Scheduler

> Generate, plan, and schedule LinkedIn content with AI-powered suggestions

![Python](https://img.shields.io/badge/Python-3.10-blue) ![Gemini](https://img.shields.io/badge/Gemini-LLM-green)

## What it does

Generate engaging LinkedIn posts with AI, create content calendars, generate hashtags, and follow best practices.

## Tech Stack

Python | Google Gemini API | Streamlit

## Setup

```bash
cd 08-linkedin-post-scheduler
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key" > .env
streamlit run app.py
```

## Features

✅ AI-powered post generation
✅ 9 topic categories + custom topics
✅ 5 content goals (branding, hiring, networking...)
✅ 6 tone options
✅ Post templates library
✅ Hashtag generator
✅ Best times to post (IST)
✅ Save & copy posts
