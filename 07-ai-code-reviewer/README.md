# 🤖 AI Code Reviewer

> Intelligent code analysis with bug detection, security fixes & optimization suggestions

![Python](https://img.shields.io/badge/Python-3.10-blue) ![Gemini](https://img.shields.io/badge/Gemini-LLM-green)

## What it does

Paste any code → Get instant AI-powered review with bugs, security issues, performance tips, and best practices.

## Tech Stack

Python | Google Gemini API | Streamlit

## Setup

```bash
cd 07-ai-code-reviewer
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key" > .env
streamlit run app.py
```

## Features

✅ Multi-language support (Python, JS, TS, Java, Go, Rust, SQL)
✅ Bug detection & error analysis
✅ Security vulnerability scanning
✅ Performance optimization
✅ Code quality scoring
✅ Best practices recommendations
