## What it does

Build your profile → Get matched to career paths → Practice mock interviews → Follow personalized learning roadmaps → Get AI career advice.

## Tech Stack

Python | Google Gemini API | Streamlit

## Setup

```bash
cd 14-ai-career-counselor
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key" > .env
streamlit run app.py
```

## Features

✅ Profile builder (skills, education, experience)
✅ Career path matching with fit scores
✅ Skill gap analysis (matched vs missing skills)
✅ AI-generated interview questions
✅ Personalized learning roadmaps
✅ Common interview questions by role
✅ AI career advisor chatbot
✅ Company insights and salary ranges
