# 📚 AI Study Assistant

> Smart learning tool: Flashcards • Quizzes • Summaries • Study Planner

![Python](https://img.shields.io/badge/Python-3.10-blue) ![Gemini](https://img.shields.io/badge/Gemini-LLM-green)

## What it does

Generate flashcards, quizzes, and summaries from any topic. Plan your study schedule with spaced repetition.

## Tech Stack

Python | Google Gemini API | Streamlit

## Setup

```bash
cd 09-ai-study-assistant
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key" > .env
streamlit run app.py
```

## Features

✅ AI flashcard generation
✅ Quiz mode with scoring
✅ Text summarization
✅ Practice questions
✅ Spaced repetition planner
✅ Weekly study templates
