# Portfolio Frontend

This folder contains the production frontend portfolio site.

## Edit content from one place

Update portfolio content in:

- `src/portfolioData.js`

That file controls personal details, featured projects, all projects, links, and technology data.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## GitHub Pages

The repository workflow `.github/workflows/deploy-portfolio.yml` builds and deploys this folder to GitHub Pages.
