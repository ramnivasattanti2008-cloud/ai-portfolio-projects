# 🤝 Contributing

Contributions are welcome! Here's how:

## 📋 Guidelines

1. Fork the repository
2. Create a branch: `git checkout -b feature/project-name`
3. Make your changes
4. Test locally: `pip install -r requirements.txt && streamlit run app.py`
5. Commit: `git commit -m 'Add project-name'`
6. Push and open a Pull Request

## 🚀 Quick Start

```bash
git clone https://github.com/ramnivasattanti2008-cloud/ai-portfolio-projects.git
cd ai-portfolio-projects
cd <project-folder>
pip install -r requirements.txt
streamlit run app.py
```
