## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/ramnivasattanti2008-cloud/ai-portfolio-projects.git
cd ai-portfolio-projects

# Pick a project
cd 01-ai-rag-chatbot

# Install dependencies
pip install -r requirements.txt

# Add API key
echo "GOOGLE_API_KEY=your_key_here" > .env

# Run
streamlit run app.py
```
