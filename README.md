### 🧠 smriti-ai — RAG Memory Assistant
> Retrieval-Augmented Generation chatbot powered by Google Gemini LLM

| | |
|---|---|
| **What** | Upload PDF/TXT/CSV → Ask questions → Get grounded answers with citations |
| **How** | Gemini Embeddings → ChromaDB → Similarity Search → Gemini LLM |
| **Tech** | Python, LangChain, ChromaDB, Gemini API, Streamlit |
| **Repo** | [`01-ai-rag-chatbot/`](01-ai-rag-chatbot/) |

```python
# Core RAG pattern
docs → chunk → embed (Gemini) → ChromaDB vector store
query → embed → retrieve top-k chunks → LLM → grounded answer + sources
```
