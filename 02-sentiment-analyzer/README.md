# 💬 Sentiment Analyzer

> AI-powered text and review sentiment analysis with visualizations

![Python](https://img.shields.io/badge/Python-3.10-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.35-red)
![TextBlob](https://img.shields.io/badge/TextBlob-NLP-green)

## What it does

Analyze text or reviews for sentiment (positive/negative/neutral) with aspect-based breakdowns, word frequency, and batch CSV processing.

## Tech Stack

| Layer | Technology |
|-------|------------|
| UI | Streamlit |
| NLP | TextBlob + NLTK |
| Visualization | Plotly |
| Data | Pandas |

## Setup

```bash
cd 02-sentiment-analyzer
pip install -r requirements.txt
streamlit run app.py
```

## Features

✅ Single text sentiment analysis
✅ Batch CSV analysis (up to 500 rows)
✅ Aspect-based sentiment (product, service, price, delivery)
✅ Spam detection
✅ Word frequency charts
✅ Sentiment distribution pie chart + histogram
✅ Download results as CSV
