# 📝 AI Meeting Notes Summarizer

> Paste meeting notes → Get structured summary, action items, decisions & follow-up emails

![Python](https://img.shields.io/badge/Python-3.10-blue?logo=python)
![Gemini](https://img.shields.io/badge/Gemini-LLM-green?logo=google)
![Streamlit](https://img.shields.io/badge/Streamlit-1.35-red?logo=streamlit)

## What it does

Paste any meeting notes → AI analyzes and extracts:
- Meeting summary (2-3 sentences)
- Attendees list
- Key discussion points
- Decisions made
- Action items with owners & deadlines
- Follow-up email draft
- Meeting minutes (downloadable)

## Tech Stack

Python | Google Gemini API | Streamlit

## Setup

```bash
cd 15-ai-meeting-notes
pip install -r requirements.txt
echo "GOOGLE_API_KEY=your_key" > .env
streamlit run app.py
```

## Features

✅ Structured meeting summary
✅ Action item extraction with owners
✅ Decision tracking
✅ Auto-generated follow-up emails
✅ Meeting minutes export
✅ Topic tagging
✅ Meeting history & search
✅ Quick templates (Sprint, Client Call, 1:1)
